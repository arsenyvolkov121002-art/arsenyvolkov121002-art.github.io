Политика конфиденциальности

Дата последнего обновления: 4 сентября 2026 года

Настоящая Политика конфиденциальности описывает, как приложение Skin Profit Bot обрабатывает информацию пользователей при использовании приложения и связанных с ним сервисов.

1. Какие данные мы получаем

Для работы приложения может потребоваться авторизация пользователя через Google. В зависимости от предоставленных разрешений приложение может получать доступ к данным Google, необходимым для работы с Google Sheets.

Приложение может обрабатывать:

  • идентификатор Google-аккаунта, необходимый для авторизации;
  • информацию, необходимую для доступа к выбранным пользователем Google Sheets;
  • данные из таблиц Google Sheets, которые пользователь разрешил приложению использовать;
  • данные, введённые пользователем для расчёта прибыли от предметов или скинов.

2. Для чего используются данные

Полученные данные используются исключительно для работы функций приложения, включая авторизацию, чтение и запись данных в Google Sheets, а также расчёт и отображение прибыли и других связанных показателей.

3. Данные Google

Приложение использует Google API для работы с данными, к которым пользователь предоставил доступ.

Мы не продаём данные Google, не используем их для рекламы и не передаём их третьим лицам, за исключением случаев, необходимых для работы приложения или предусмотренных законодательством.

4. Хранение данных

Приложение стремится хранить только те данные, которые необходимы для предоставления функций сервиса.

Данные, находящиеся в Google Sheets, продолжают храниться в аккаунте пользователя в соответствии с настройками и политиками Google.

5. Передача данных третьим лицам

Мы не продаём и не сдаём в аренду персональные данные пользователей. Данные могут быть переданы третьим сторонам только в случаях, когда это необходимо для работы приложения, выполнения требований закона или защиты прав и безопасности.

6. Безопасность

Мы принимаем разумные технические и организационные меры для защиты обрабатываемой информации от несанкционированного доступа, изменения, раскрытия или уничтожения.

7. Удаление доступа и данных

Пользователь может в любой момент прекратить использование приложения и удалить предоставленный приложению доступ к своему Google-аккаунту через настройки Google-аккаунта.

Пользователь также может удалить данные из своей Google Sheets.

8. Сторонние сервисы

Для работы приложения могут использоваться сторонние сервисы, включая Google и Google Sheets. Использование таких сервисов регулируется их собственными политиками конфиденциальности.

9. Изменения политики конфиденциальности

Мы можем периодически обновлять настоящую Политику конфиденциальности. Новая версия будет опубликована на этой странице с указанием даты обновления.
